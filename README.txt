MY A17 DASHBOARD

1. Upload index.html to a static website host (GitHub Pages is free) or open it in a browser for a quick local test.
2. Visit the published HTTPS website in Chrome on your Galaxy A17.
3. Tap Chrome's ⋮ menu > Add to Home screen (or Install app if offered).
4. Optionally set Chrome > Settings > Homepage to the published website address if your Chrome version offers a custom URL.

Features:
- Google search
- Daily SFW anime image (random image cached for the day; New anime art forces a refresh)
- City-based Google News headlines through RSS2JSON
- Six Wikipedia topic search results
- Local bookmarks, dashboard activity history, and notes via localStorage
- Ten rotating daily vocabulary entries

Notes:
- News and topic search require internet access and third-party services. Free endpoints may occasionally rate-limit or change.
- Location permission is optional. If granted, the page attempts to infer a city using OpenStreetMap Nominatim. Otherwise enter a city manually.
- Browser security may limit some functions when opening the file directly; use an HTTPS static host for normal use.
- This page tracks only searches and links used from this dashboard, not Chrome's full browsing history.
