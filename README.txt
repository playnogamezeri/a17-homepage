MY A17 DASHBOARD — VERSION 5

A mobile-first personal homepage designed for Chrome on the Samsung Galaxy A17.

INSTALL / UPDATE
1. Publish this repository with GitHub Pages (Settings → Pages → Deploy from a branch → main → /root).
2. Open the published HTTPS website in Chrome on your Galaxy A17.
3. Tap Chrome's ⋮ menu → Add to Home screen (or Install app, if offered).
4. To update the dashboard later, replace index.html in this repository with the newer version and commit the change.

FEATURES
- Google search and a live clock/date greeting.
- Daily SFW anime background, cached for the local calendar day, with a button to request new art.
- Local and world news based on a city entered by the user; optional location permission can suggest a city.
- Topic Explorer with separate search links for YouTube, Reddit, TikTok, Instagram, X, and Facebook.
- Local Events & Live Entertainment search links covering the next seven calendar days, including weekends.
- Celebrity News feeds labeled [ARTISTS], [ACTORS], [MODEL], [POLITICIAN], and [INTERNET FAME].
- Now in Theaters links for finding current movies and nearby showtimes.
- Ten rotating Daily Vocabulary words, with definitions and example sentences.
- Mood Selector with ten moods: Bored, Horny, Angry, Sad, Cheerful, Relaxed, Energetic, Curious, Lonely, and Adventurous.
- Recent activity history for searches and links opened from this dashboard.
- Quick notes saved in this browser on this device.

IMPORTANT LIMITATIONS
- Topic Explorer, event searches, and movie/showtime links open searches on external services; they are not a unified social-media search engine or a verified live event/showtime database.
- News and celebrity headlines use Google News RSS through RSS2JSON. Third-party services can rate-limit, change, or become temporarily unavailable.
- Event and movie search results depend on the selected city and the external services.
- The daily refresh checks for a new local calendar date while the page is open, and reopening the page also loads current content. It is not a background task when the browser is closed.
- The Mood Selector's Horny option links to adult wellness, sexual health, consent, and relationship information rather than pornography.
- The Sad option emphasizes non-graphic humanitarian reporting and support resources.
- Notes, city selection, and activity history use local browser storage on this device. This dashboard does not track the full Chrome browsing history.
- An internet connection is required for external images, headlines, and search links.

CHROME HOMEPAGE NOTE
Android Chrome may not allow a custom webpage to replace its built-in New Tab page. Adding the published site to the Home screen gives you a convenient app-like shortcut.
